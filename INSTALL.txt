MediaKeep 1.0.1 — 20 languages — Apple Craft

macOS 13+, Apple Silicon: Quit the old app, open the DMG, drag MediaKeep.app into Applications.
Windows 10/11 x64 and Windows 11 ARM64: Run the matching Setup EXE and open MediaKeep from the Start menu. To use a portable ZIP, extract all files and keep _internal next to MediaKeep.exe.
Linux x86-64 (Ubuntu 22.04+ baseline): Extract the archive, then run ./MediaKeep/MediaKeep from a desktop session.

The interface starts in English. Choose from 20 languages in Settings > App Language. Settings > Appearance offers seven themes.
Choose Video Download or Audio Extraction, select a source, quality, subtitles/audio and save folder, then start.
Only source-provided subtitles and dubbed audio are used. MediaKeep does not generate AI translations or voice dubbing.

Users of the legacy 1.2.x series must install the current release manually once. Subsequent updates can be checked from the app menu.
The Mac build is locally signed without Apple notarization. The Windows build is unsigned. Verify the download source before allowing the application to run.
