**保存需要的视频片段，轻松提取 MP3。**

MediaKeep 是适用于 macOS、Windows 和 Linux 的免费桌面应用。无论是复习教程中的重点，还是保留自己录制的访谈声音，都可以将文件直接保存到指定文件夹。支持包括简体中文在内的 20 种界面语言和 7 种主题。

[英文宣传视频](https://youtu.be/n7L9ymqGF9I)

## 主要功能

- 预设最多 9 个常用文件夹，按项目整理下载内容。
- 将完整视频或指定起止时间的片段保存为 MP4，也可从本地视频或受支持的链接提取 MP3。
- 默认画质上限为 4K（2160p），应用会选择不超过设定上限的最佳可用画质。如果来源提供对应语言的字幕或配音，可优先选择。

## 使用方法

macOS：打开 DMG，将应用拖入“应用程序”。Windows：运行适合设备的安装程序后从开始菜单启动。Linux：解压并运行 MediaKeep。

在 **Settings → App Language** 中选择简体中文。粘贴链接，按需指定片段，再选择保存位置。只需要声音时使用音频提取。

## 使用说明

字幕和配音由来源提供。应用不会提升源视频分辨率，也不会生成翻译或配音。保存片段时仍可能需要获取完整源视频。请仅保存或转换你有权使用的内容。
