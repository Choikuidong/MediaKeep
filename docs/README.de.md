# MediaKeep

[English](../README.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [简体中文](README.zh-Hans.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português (Brasil)](README.pt-BR.md)

**Videoclips speichern und Ton als MP3 extrahieren.**

MediaKeep ist eine kostenlose Desktop-App für macOS, Windows und Linux. Speichern Sie einen Abschnitt aus einem Tutorial oder extrahieren Sie den Ton aus einem selbst aufgenommenen Interview. Es gibt 20 Oberflächensprachen, darunter Deutsch, und sieben Designs.

**YouTube-Downloads.** Speichern Sie das ganze Video oder einen ausgewählten Ausschnitt als MP4. Auch die Tonspur, etwa Musik, lässt sich über einen YouTube-Link als MP3 speichern.

[Englisches Vorstellungsvideo](https://youtu.be/n7L9ymqGF9I)

## Funktionen

- Wählen Sie den Zielordner vor dem Speichern und hinterlegen Sie bis zu neun Favoriten.
- Speichern Sie ein vollständiges Video oder legen Sie Start und Ende für einen MP4-Clip fest. Extrahieren Sie MP3 aus lokalen Videos oder unterstützten Links.
- Die App wählt die beste verfügbare Qualität bis zur gewählten Obergrenze, standardmäßig 4K (2160p). Wenn die Quelle passende Untertitel oder eine Synchronfassung anbietet, kann die gewählte Sprache bevorzugt werden.

## Erste Schritte

Öffnen Sie unter macOS das DMG und ziehen Sie die App in den Programme-Ordner. Führen Sie unter Windows das passende Setup aus und öffnen Sie MediaKeep im Startmenü. Entpacken Sie unter Linux das Archiv und starten Sie die App.

Wählen Sie Deutsch unter **Settings → App Language**. Fügen Sie den Link ein und wählen Sie Zielordner und bei Bedarf einen Zeitbereich aus. Für reinen Ton verwenden Sie die Audioextraktion.

## Hinweise zur Nutzung

Untertitel und Synchronfassungen stammen aus der Quelle. Die App erstellt keine Übersetzungen, keine Synchronfassungen und keine höhere Auflösung. Für Clips kann der vollständige Download der Quelle nötig sein. Speichern oder konvertieren Sie nur Inhalte, für die Sie die Erlaubnis haben.
