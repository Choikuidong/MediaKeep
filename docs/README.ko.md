# MediaKeep

[English](../README.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [简体中文](README.zh-Hans.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português (Brasil)](README.pt-BR.md)

**필요한 영상과 소리만, 원하는 폴더에.**

MediaKeep은 macOS·Windows·Linux에서 무료로 사용할 수 있는 앱입니다. 긴 강의에서 다시 볼 부분이나 직접 촬영한 인터뷰의 소리를 골라 원하는 폴더에 저장할 수 있습니다. 한국어를 포함한 20개 인터페이스 언어와 7가지 테마를 지원합니다.

**YouTube 동영상 저장** — 전체 영상이나 필요한 구간만 MP4로 다운로드할 수 있습니다. 음악처럼 소리만 필요할 때는 YouTube 링크에서 오디오를 MP3로 저장할 수 있습니다.

[영어 소개 영상](https://youtu.be/n7L9ymqGF9I)

## 주요 기능

- 자주 쓰는 저장 위치를 최대 9개 등록하고 원하는 폴더에 바로 저장하세요.
- 영상 전체 또는 시작·종료 시간을 지정한 구간을 MP4로 저장하세요. 내 영상이나 지원되는 링크에서 소리만 MP3로 추출할 수도 있습니다.
- 기본 상한은 4K(2160p)이며, 선택한 상한 이하에서 가능한 최고 화질을 고릅니다. 원본에 해당 언어의 자막이나 더빙 음성이 있으면 설정에 따라 우선 선택합니다.

## 사용 방법

Mac은 DMG에서 앱을 응용 프로그램 폴더로 옮깁니다. Windows는 PC에 맞는 설치 파일을 실행한 뒤 시작 메뉴에서 앱을 열고, Linux는 압축을 풀어 실행합니다.

**Settings → App Language**에서 한국어를 선택하세요. 동영상 다운로드 탭에서 링크를 입력하고, 저장 위치와 필요한 경우 구간을 지정합니다. 소리만 필요하면 오디오 추출 탭을 사용하세요.

## 이용 안내

자막·더빙은 원본 제공 여부에 따라 달라집니다. 새 번역과 더빙을 만들거나 화질을 업스케일하지 않습니다. 구간을 지정해도 원본 전체를 먼저 받을 수 있습니다. 다운로드·변환 권한이 있는 콘텐츠에만 이용해 주세요.
