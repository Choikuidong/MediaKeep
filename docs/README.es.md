# MediaKeep

[English](../README.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [简体中文](README.zh-Hans.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português (Brasil)](README.pt-BR.md)

**Guarda los fragmentos que te interesan y extrae audio en MP3.**

MediaKeep es una aplicación de escritorio gratuita para macOS, Windows y Linux. Guarda la parte de un tutorial que quieres repasar o extrae el audio de una entrevista propia. La interfaz está disponible en 20 idiomas, incluido el español, y ofrece siete temas.

**Descargas de YouTube.** Guarda el vídeo completo o un fragmento como MP4. También puedes guardar solo el audio, como música, en formato MP3 desde un enlace de YouTube.

[Vídeo promocional en inglés](https://youtu.be/n7L9ymqGF9I)

## Qué puedes hacer

- Guarda archivos directamente en la carpeta que elijas y conserva hasta nueve ubicaciones favoritas.
- Guarda el vídeo completo o marca el inicio y el final de un fragmento en MP4. También puedes extraer MP3 de vídeos locales o enlaces compatibles.
- Selecciona automáticamente la mejor calidad disponible dentro del límite elegido, que por defecto es 4K (2160p). Puedes priorizar subtítulos y doblaje en el idioma elegido si la fuente los ofrece.

## Cómo empezar

En macOS, abre el DMG y arrastra la aplicación a Aplicaciones. En Windows, ejecuta el instalador adecuado y abre MediaKeep desde Inicio. En Linux, extrae el archivo y ejecuta MediaKeep.

Elige Español en **Settings → App Language**. Pega el enlace, elige una carpeta y, si quieres, indica un intervalo. Para guardar solo el audio, abre la pestaña de extracción de audio.

## Uso responsable

La disponibilidad de subtítulos y doblaje depende de la fuente. La aplicación no aumenta la resolución ni crea traducciones o doblajes. Guardar un fragmento puede requerir descargar el original completo. Usa solo contenido que tengas permiso para guardar o convertir.
