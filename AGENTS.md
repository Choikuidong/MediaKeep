# Repository publishing language

All GitHub-facing content must be written in English: README files, guides, release notes, issue and pull-request text, workflow names and descriptions, commit messages, sponsorship text, and future announcements.

Keep the application's 20-language translations and source-language fixtures intact. This policy applies to publishing and documentation, not to removing supported interface languages or altering third-party license texts.

Describe automatic quality selection accurately: the app selects the best available stream up to the selected limit, with 4K as the default ceiling. Describe language-aware subtitles and dubbed audio as source-provided and available only when the original service supplies them. Do not claim automatic AI translation, new voice dubbing, or upscaling.

Emphasize user-selected save folders, nine folder shortcuts, and saving a full video or a custom range. Do not imply that selecting a range always reduces network usage.

Use the verified GitHub Sponsors account in .github/FUNDING.yml for sponsorship links. Never change financial account details or make payments as part of documentation work.
